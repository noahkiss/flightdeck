# GFF v0.6.0

This release covers the pull requests merged since v0.5.0. A message sent after Stop now reaches
the agent, moving a group drains its work safely, and the hab API gains device management and two
activity events.

## Breaking or needs action

- **The Capcom engine needs Node.js 24 or later.** gff-hab refuses to start the engine with an
  older Node.js and names the version it needs.
- **`session.close` refuses a session that may still run.** It answers `conflict`. It removes
  only an exited session's record.
- **Ten peer-link methods answer `denied` to clients.** They work only over a link between habs.
  The Swift package no longer has them. The wire names are unchanged, so habs on different
  versions still talk to each other.
- **Run `gff-hab install` again after you update.** The service keeps running the old build
  until you do. With Homebrew: `brew upgrade gff`, then `gff-hab install`. Running programs keep
  running.

## Sessions

- **Send after Stop.** After the owner stops Claude with Esc, the next message or Send Now is
  delivered. Before, the hab published no new state when Claude went idle, so the client waited.
- **Live Activity.** The update that removes Allow and Deny goes at high priority, so iOS shows
  the answered state promptly.

## Groups

- **`[groups] move_drain`.** A moving group's lane takes no new work. A run that has not pushed
  stops and its item returns to the front of the queue. A run that has pushed gets up to
  `move_drain` (10 minutes) to finish.
- **A move stops the old home's lane run** and removes its lane worktree.
- **Close and end wait for a drain.** They answer `unavailable` while a move is draining.
- **Start-up sweep.** gff-hab removes lane worktrees that no group uses. It never prunes other
  worktrees of your checkout.

## Hab API

- **`devices.list` and `devices.revoke`.** Revoke removes the device's key line and keeps a
  record. Its push registration stays until push revocation is built. `devices.pair` over the
  API answers `unavailable`; pair with `gff-hab pair`.
- **`pane.activity`** goes out after a client types into a pane, at most once a second per client
  and pane.
- **`session.turn_end`** goes out when a turn ends in `done` or `error`, with the final message
  when a chat reader is already open.
- The schema revision stays 1.

## Other changes

- Eight timing flakes in the Go tests are fixed.
- The Claude Agent SDK is 0.3.332, the Anthropic SDK 1.14.0 and the Codex SDK 0.172.0.
- libghostty moves to Ghostty 74d1983f27eb, and sherpa-onnx to 2.0.3.
